# ABSTRACT

The Cybersecurity Log Analyzer is a web-based application designed to analyze system and application log files and identify potentially suspicious activities.

Log files contain important information about user activities, login attempts, system errors, and security events. Manually examining these logs can be time-consuming.

This project provides a simple dashboard that allows users to upload log files, analyze events, identify suspicious activities, and view security alerts.

The system classifies events into four severity levels: Critical, High, Medium, and Low. It also provides event statistics, source IP identification, search functionality, filtering, and CSV report generation.

The application uses HTML, CSS, and JavaScript for its frontend and Python with Flask for its optional backend.

# 1. INTRODUCTION

Cybersecurity is an important aspect of modern information technology. Organizations use computer systems and networks to store and process sensitive information.

Log files record different activities performed within computer systems and applications.

These logs help security professionals understand system behavior and identify suspicious activities.

The Cybersecurity Log Analyzer is developed to simplify the process of examining log files through a user-friendly web interface.

It identifies important events using predefined keyword-based detection rules and displays the results in an organized dashboard.

# 2. PROBLEM STATEMENT

Manually analyzing large log files is difficult and time-consuming.

Security-related events such as repeated failed login attempts, unauthorized access, suspicious commands, and malware indicators may be overlooked.

Therefore, a simple tool is required to analyze log files and highlight potentially suspicious activities.

# 3. OBJECTIVES

The main objectives are:

1. To develop a web-based cybersecurity monitoring dashboard.
2. To upload and analyze text-based log files.
3. To identify potentially suspicious activities.
4. To classify events according to severity.
5. To identify source IP addresses.
6. To provide search and filtering facilities.
7. To generate downloadable CSV reports.
8. To demonstrate practical cybersecurity skills.

# 4. SCOPE OF THE PROJECT

The project focuses on basic security log analysis.

It can be used for educational demonstrations and analyzing authorized sample or system logs.

The application supports:

- Text-based log file uploads.
- Failed login identification.
- Suspicious activity indicators.
- Severity classification.
- Event monitoring.
- CSV report generation.

# 5. EXISTING SYSTEM

In the traditional approach, security administrators manually inspect log files to identify unusual activities.

Disadvantages:

- Time-consuming analysis.
- Difficulty identifying repeated events.
- Possibility of human errors.
- Lack of organized reporting.
- Difficult monitoring of large log files.

# 6. PROPOSED SYSTEM

The proposed system provides an automated, rule-based log analysis interface.

Users upload a log file, and the application processes the entries and identifies security-related keywords.

The results are displayed through dashboard metrics, charts, and an event table.

Main features:

- Dashboard overview.
- Log file upload.
- Security event detection.
- Severity classification.
- Source IP identification.
- Search and filtering.
- CSV report export.
